# Week 5 — Category C Problems

Five problems focused on arrays, loops, conditionals, method overloading, and OOP fundamentals.

## Problems

| # | Problem | File | Difficulty | Key Concepts |
|---|---------|------|------------|--------------|
| 1 | Hackathon Score Curve Booster | `HackathonScoreCurveBooster.java` | Easy | In-place array modification, pass-by-reference, `Arrays.toString()` |
| 2 | Duplicate Team Name Finder | `DuplicateTeamNameFinder.java` | Easy | Nested loops, `String.equals()`, pairwise comparison |
| 3 | Top-3 Podium Finder | `TopThreePodiumFinder.java` | Intermediate | Single-pass traversal, running maximums, ties handling |
| 4 | Hackathon Seating Grid Optimizer | `HackathonSeatingGridOptimizer.java` | Intermediate | 2D jagged arrays, helper methods, method decomposition |
| 5 | Placement Drive Shortlisting Engine | `PlacementDriveShortlistingEngine.java` | Advanced | Method overloading, `Comparable<T>`, `Arrays.sort()`, encapsulation |

## How to Compile & Run

```bash
cd week5/category_c

# Compile all
javac *.java

# Run individually
java HackathonScoreCurveBooster
java DuplicateTeamNameFinder
java TopThreePodiumFinder
java HackathonSeatingGridOptimizer
java PlacementDriveShortlistingEngine
```
