## 🚀 Compilation and Execution

### Compile All Files
`ash
# Compile Live Coding Session
javac week1/live_coding_session/*.java

# Compile Assignments
javac week1/assignments/*.java

# Compile Practice Concept Files
javac week1/StringPractice.java week1/ExceptionPractice.java
`

#### Live-Coding Session
- java week1.live_coding_session.RockPaperScissorsGame
